# Issue #4 Interfaces — consolidated Specify draft

## Status and conventions

Approved behavior is summarized in design.md. P1 names and adapters were approved
with revised S35; they are project contracts, not already installed library APIs. Discussion history is retained
in [history/interfaces-discussion.md](history/interfaces-discussion.md).

N: environment count; L: levels (10); C=20: terrain columns; J=12; F=4; H=240; W=320.
Floating tensors: torch.float32 on env.device unless stated; indices/IDs int64;
validity masks bool. SI units. Base axes +X forward,+Y left,+Z up. Quaternions wxyz.
Canonical joints: FL,FR,RL,RR, each hip-abduction/thigh/calf. Feet same leg order.

No additional terminal observations. `step()` retains native observation/reward/
terminated/truncated/extras contract; done-row observations are new-episode values.
No model latent is generated by the environment. Consumers retaining data across
steps must copy it; held buffers may be reused on a future legitimate capture.

### metadata dictionary — proposed keys and lifecycle

- `episode_id`: int64[N], increments on each row reset.
- `low_rate_capture_time`: float32[N], seconds since that row's reset.
- `low_rate_age`: float32[N], current sensor clock minus capture time.
- `low_rate_valid`: bool[N], an aligned post-reset target sample exists.
- `depth_valid`: bool[N,H,W,1]; body/foot/critic validity fields match their arrays.
- `base_height_valid`: bool[N,1].

Capture times must agree across low-rate sensors before publishing valid bundle;
a scheduling mismatch is an integration error, not silent data relabelling. Initial
invalid buffers must not be advertised as genuine zero-depth/height observations.
Episode completion flags come from native step outputs and optional outcome-only
extras, not an extra terminal observation. No additional mask policy silently
changes learner timeout bootstrapping. Native termination/truncation conventions are approved by S58.

### build_terrain_layout(difficulty: float, cfg: ParkourSubTerrainCfg) -> TerrainLayout

Purpose: one deterministic source for geometry and task regions. Inputs d in[0,1],
explicit seed/schema version and approved family config; outputs local metric layout,
spawn, ordered gates, legal region, completion bounds and support surfaces. Local
frame corner coordinates span[0,size_x]x[0,size_y], task +X forward. Mirror reflects
Y about the tile center and transforms all region/surface orientations.

No I/O/global RNG. Invalid d/dimensions, nonfinite geometry or unavailable safe
spawn/landing produce ValueError with family/parameter context; no silent clipping.
Defaults derive from approved config table, except unresolved P2. Exact shape
representation of gates/surfaces awaits P2, so TerrainLayout is not yet a complete
frozen public type.

### Project sub-terrain configuration/function pairs

Config classes inherit official SubTerrainBaseCfg via @configclass and use the
same function resolution conventions. Functions accept(difficulty,cfg) and return
(list[trimesh.Trimesh], np.ndarray origin shape[3]); finite metres. They consume
TerrainLayout, never add arbitrary extra items to the official return signature.
Statically computed origin remains separate from task spawn. Source convention
compatibility is pinned to the inspected commit; mesh winding/normals validated.

### ParkourTerrainGenerator / ParkourTerrainImporter

Subclass official classes, selected through cfg.class_type. Generator captures
actual d/effective cfg on every `_get_terrain_mesh` call, including cache hits;
`_add_sub_terrain` associates layout with(level,column). Placement transforms must
include native centering exactly once. Use deterministic geometry seed+d+config+
schema version; row/column only affect placement unless explicitly in cache key.

After generation attach complete table to in-memory `terrain_mesh.metadata` under
`r3la_task_regions`. Importer override of public import_mesh validates/extracts it,
then delegates native import. No reliance on OBJ metadata persistence; no replacement
of constructor/physics import pipeline. Missing/inconsistent metadata fails setup.
Expose `task_regions` indexed[L,C]; family ID is separate from native terrain_types
column index. Store actual d, canonical identity/mirror sign, tile-world transform,
spawn/gates/regions/support surface. Mesh and metadata must match cache-on/off.
P2 determines numeric fields and final row-table schema.

## P1 approved sensor API and ownership

### HeldDepthCameraCfg / HeldDepthCamera

Config extends official CameraCfg with approved calibration and update_period0.1,
update_latest_camera_pose=True. Subclass Camera; override capture hook to delegate
native render then immediately copy/sanitize only captured env rows into owned
float32 depth and bool mask buffers. A delayed copy after another subset render
is insufficient. Native batching is disabled by the scalar-hook override in this
version; do not claim unchanged batching performance.

`read_sample() -> SensorSample`: trigger native `.data` read, return held metric
values, validity, capture_time/age/episode identity. Repeated reads before next
capture preserve values. `reset(env_ids=None, env_mask=None)` delegates native reset,
invalidates only selected held rows and advances their episode identity. No extra
physics step and no custom clock. Borrowed snapshot storage stays stable against
renderer writes, but may change on a future own-row capture; retained trajectories
must clone at their collection boundary.

Private native timestamps/frame/mask access stays inside adapter. Mismatched shape,
nonfinite configuration or unsupported renderer contract is a setup error. Invalid
pixels are normal data with masks, not configuration exceptions. Partial resets,
reset-event pose freshness and all-row renderer writes need bounded validation.

### BaseYawHeightScannerCfg / BaseYawHeightScanner

Subclass selected NewtonRaycastSensor; config identifies reference-body prim and
independent base heading prim, pattern, period and global_world_only=True. Register
both pose sites before model finalization; resolve maps in native initialization.
Compose reference-body translation and base orientation in persistent Warp buffers
for the native yaw-alignment ray kernel. Keep native query/reset/sampling behavior.
Launch offset belongs to ray starts, not physical reference Z. Expose metric heights,
bool masks and native capture metadata. No-hit is zero+false. Missing pose mapping,
invalid grid or unsupported backend raises a clear setup error. S53 fixes ray reach.

### read_low_rate_targets(env) -> named sample bundle

One accessor reads depth/body/four-foot sensors through normal target path, checks
capture-time/reset identity alignment, and exposes approved values/masks/metadata.
No independent sampling schedule, fresh random noise or physics advancement.
Disable normal debug/other-substep readers that would shift target sampling phase.
This is a proposed project accessor, not an existing atomic IsaacLab operation.

## P1 approved attempt and curriculum APIs

Locations under existing `src/r3la/tasks/velocity/mdp`: attempts.py, terminations.py,
curriculums.py, commands.py; observations/rewards/events remain existing modules.

### ParkourAttemptState(ManagerTermBase) — approved revised S35

A native stateful termination term owns task-specific passage progress, landing
window, outcome flags and q*dt/duration accumulators. Other callbacks retrieve the
instance through the public termination-manager accessor. Guard updates with the
native common_step_counter; multiple readers must not advance a transition twice.
Setup probes do not advance attempts. Native base-contact and timeout terms retain
their responsibilities; final outcome arbitration must not depend on term order.
No finalized-record queue, consumed flags, second episode counter or scheduler.

The native curriculum callback reads ending rows directly before reset clears them.
Only task-computed completion on the current transition counts; startup, explicit
reset without completion and UI-only reset contribute no attempt. Native term
reset clears per-attempt state after curriculum evaluation. No observation snapshots.
Boundary metadata must not alias buffers subsequently cleared during reset.

### ParkourCurriculum(ManagerTermBase)

One native CurriculumTermCfg stateful term owns separate persistent terrain success
windows and speed batches. __call__(env, env_ids) reads valid ending rows, updates
statistics and assigns next terrain before reset events and command reset. Native
_reset_idx supplies invocation timing; no additional consume protocol. Approved
simultaneous ordering: ascending env ID, updating statistics and making next-attempt
decisions per row. Only ending environments migrate. Approved S5–S8 defaults apply.
Return logging tensors; reset(env_ids) preserves cross-episode windows/batches.
Evaluation disables curriculum changes.

Score uses pre-reset accumulated q divided by actual duration, including the ending
step. Command metrics update after autoreset; reward reset logs divide by maximum
rather than actual episode duration. Private reward episode sums also couple the
score to reward weights. Retain the task-specific q accumulator instead.

### ParkourVelocityCommandCfg / ParkourVelocityCommand(CommandTerm)

A minimal task sampler retains the native CommandTerm reset/countdown/compute
lifecycle. command is float32[N,3]: sample vx~U[0,vmax_family] from the newly assigned
family's updated bound, with vy=yaw=0. No heading conversion, standing override or
success-rate metric. Curriculum owns bounds and policy; evaluation uses fixed command.

Use native resampling_time_range=(T,T), T=max_episode_length_s+step_dt, and validate
T exceeds the episode limit. This accommodates the immediate post-reset countdown
and prevents normal in-episode resampling. No custom reset-only scheduler. Custom
sampling is needed for family-specific bounds, not command constancy. Reject negative
or nonfinite bounds, max<initial and invalid evaluation commands. Do not duplicate
tracking accumulation here. Unmodified UniformVelocityCommand uses shared ranges
and local velocity-success logging; a minimal CommandTerm avoids overriding several
of its metric/reset methods.

### reset_parkour_state(env, env_ids, ...)

Event callback uses assigned task spawn plus approved jitter, local surface height
and nominal joint state settings, through official asset write APIs. No pushes.
Must execute after next terrain assignment; stale origin-only reset is invalid.
Nominal evaluation reset has zero jitter. Full spawn footprint containment is checked
against layout; geometry feasibility is a setup check, not silently altered physics.

## S55/S56 approved reward timing/action history

RewardManager supplies step_dt=0.02 s scaling once, after weighted reward summation.

between environments. Tests must cover first/second/third actions and partial reset.

## S66 — proposed final names and TerrainLayout schema

Status: Proposed for final interface approval. Earlier amendment history is retained;
S59–S65 override fixed-count/platform/tilt descriptions above.

Freeze existing output names and the AMP keys in this document. Metadata keys:
episode_id:int64[N]; low_rate_capture_time:float32[N] seconds since row reset;
low_rate_age:float32[N] seconds; low_rate_valid:bool[N]; depth_valid:bool[N,240,320,1];
body_height_valid:bool[N,286]; lf_height_valid/rf_height_valid/lh_height_valid/
rh_height_valid:bool[N,25]; critic_height_valid:bool[N,187];
base_height_valid:bool[N,1]. No new concatenated observation features. Reset identity
is metadata only, not a second attempt scheduler. All adapters/accessors must agree
on the row reset identity; reset invalidates only selected rows. At a valid initial
post-reset capture its time/age are zero. Mask shape/dtype errors fail validation.

Proposed immutable generation-time project records (NumPy float64 metre geometry;
Python integer/string IDs), converted once into device tensors for runtime:

| Record / field | Type / meaning |
| --- | --- |
| TerrainLayout.schema_version | int, initial1; include in cache identity |
| family | enum box,gap,stairs,tilted_stairs,side_slope,rough_grid |
| seed, canonical_id | int seed and str reproducible sample identity |
| difficulty, mirror_sign | float in[0,1], int +1/-1; sign flips local Y |
| tile_size | float64[2], default[10,10] m |
| spawn_pos, spawn_yaw | float64[3] ground-reference position, float radians; root height offset applied by reset |
| legal_xy | float64[2,2], rows[min,max], columns[x,y] |
| gates | ordered tuple[Gate]; Gate has x:float, y_bounds:float64[2] |
| completion_xy | float64[2,2] inset rectangle; success also requires legal_xy |
| support_surface | PlaneRegion with full xy_bounds and unit normal n[3], offset c; n dot p+c=0 |
| geometry | tagged family-specific immutable data, described below |

geometry includes actual dimensions/heights: box height/top bounds; gap width/depth/
landing bounds; stairs count/rise/tread depth/holes/platform XY/top height and tread
planes; slope break-line X values and analytic transverse profile; rough-grid cell
edges and height matrix[10,10]. All derive from the same seed/config/d sample used
for mesh creation; no second draw. Return both nominal spawn ground reference and
actual support geometry rather than deriving success from mesh origin.

Gate locations: box entrance at x3 (one gate, followed by top completion); gap,
slope and grid entrance x3 plus far edge; stairs entrance x3 plus platform near
edge. Gate y bounds use designated traversable surface intersected with corridor.
For holes=False stairs use actual tread width; for True use configured tread span;
platform gate uses actual platform span. Reset passes no gate implicitly. Surface
planes describe target support only, not all rough-grid/transition triangles.

Placement record adds level:int, column:int and tile-to-world rigid transform
float64[4,4]; mirror is reflected in geometry/regions before placement. Runtime
storage uses float32 on env.device, IDs int64/masks bool and indexes [L,C,...];
variable gate/tread arrays may be padded with counts/masks, not exposed as a new
learner observation. World normal/offset transform consistently with points.

Construction rejects nonfinite values, invalid dimensions, empty inset/corridor
intersection, nonunit/invalid normals or inconsistent gate order with ValueError
including family/config context. No silent clipping/resizing. Schema-version
changes invalidate cached layout identity. Names are project APIs, not claims
that upstream IsaacLab exposes these records. No serialization/network contract.
