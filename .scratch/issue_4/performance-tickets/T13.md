# T13: 低频传感器校验提速并保持完整读取契约

Published: https://github.com/MrCCaesar/r3la/issues/17
Label: ready-for-agent. Parent: #4. Native blocking relationships are used on GitHub.

## Parent

https://github.com/MrCCaesar/r3la/issues/4

## What to build

让低频目标完整读取接口在保持采样、输出和报错行为的前提下，减少有效数据路径上的 CPU/GPU 同步。先提取共享的已验证样本读取边界，再集成固定形状的合并校验，使现有调用者无需更改即可受益。

## Acceptance criteria

- [ ] 保持六传感器读取顺序、结构检查及公开完整数据接口，值/掩码/元数据与基线等价，不引入跨调用缓存或新调度器。
- [ ] 有效对齐校验合并为一个主机可见判断；异常时仅对同一批样本按原逐传感器顺序诊断，保持异常类型、文本和优先级，不再次采样。
- [ ] 以独立基线对照覆盖计时容差边界、NaN/Inf、未捕获行、空合格集合、错误形状/类型/设备及多个同时错误；现有传感器测试通过。
- [ ] 原生有界传感器检查保持低频采样、部分重置隔离、校准和 RGB/深度输出；同步说明实现和证据。
