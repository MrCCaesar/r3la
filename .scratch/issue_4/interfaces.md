## Action contract — approved

Finite float [N,12], canonical order, env.device; official JointPositionAction with
scale0.5 rad/unit, use_default_offset=True, preserve_order=True, clip=None.
Targets q_default+0.5*a, rad. Keep official Go2 nominal actuator model and limits.
Default reset velocities zero; last-action buffer resets through native manager.
Bad shape/device/nonfinite action must produce a clear failure in checks rather
than silently reordering/padding values; exact runtime checks should avoid imposing
unnecessary per-step host synchronization.

### Implemented explicit action check — T08

Project utility `validate_parkour_actions(env, actions) -> None` implements the
approved action-input checks. `env` supplies num_envs:int and device (the resolved
simulation device); actions must be torch.float32[N,12] on that device, finite,
dimensionless and in canonical order. There is no clipping/range limit, padding,
reordering or device conversion. Raises TypeError for non-Tensor/dtype inputs and
ValueError for shape/device/nonfinite values. No optional flags or hidden mutation.

This is an explicit input/verification boundary, not a new action term or environment
loop. Invoke it before submitting untrusted input; it is not automatically installed
in `env.step()`. The native environment permits device transfer and some broadcasting
when callers bypass the check. Finiteness checks synchronize GPU results with the
host, so trusted normal steps retain the approved official JointPositionAction path.

### Installed native manual-reset lifecycle note — T08

A manual `env.reset(env_ids=...)` clears only selected history rows, then computes
observations for all rows with native history append enabled. Selected rows backfill
five copies of their new noisy frame; non-reset rows append one observation and retain
their previous four frames, even when no physics transition occurs during that manual
reset call. Ordinary step/autoreset behavior retains one returned sample per step.
Read-only observation-manager calls do not append history. These are installed
native lifecycle facts, not an additional sampler or changed episode scheduler.

### ParkourAttemptState(ManagerTermBase) — approved revised S35

A native stateful termination term owns task-specific passage progress, landing
window, outcome flags and q*dt/duration accumulators. Other callbacks retrieve the
instance through the public termination-manager accessor. Guard updates with the
native common_step_counter; multiple readers must not advance a transition twice.
Setup probes do not advance attempts. Native base-contact and timeout terms retain
their responsibilities; final outcome arbitration must not depend on term order.
No finalized-record queue, consumed flags, second episode counter or scheduler.

The native curriculum callback reads ending rows directly before reset clears them.

reset without completion and UI-only reset contribute no attempt. Native term
reset clears per-attempt state after curriculum evaluation. No observation snapshots.
Boundary metadata must not alias buffers subsequently cleared during reset.

### ParkourCurriculum(ManagerTermBase)

One native CurriculumTermCfg stateful term owns separate persistent terrain success
windows and speed batches. __call__(env, env_ids) reads valid ending rows, updates
statistics and assigns next terrain before reset events and command reset. Native
_reset_idx supplies invocation timing; no additional consume protocol. Approved
simultaneous ordering: ascending env ID, updating statistics and making next-attempt
decisions per row. Only ending environments migrate. Approved S5–S8 defaults apply.
Return logging tensors; reset(env_ids) preserves cross-episode windows/batches.
Evaluation disables curriculum changes.

Score uses pre-reset accumulated q divided by actual duration, including the ending
step. Command metrics update after autoreset; reward reset logs divide by maximum
rather than actual episode duration. Private reward episode sums also couple the
score to reward weights. Retain the task-specific q accumulator instead.

### ParkourVelocityCommandCfg / ParkourVelocityCommand(CommandTerm)

A minimal task sampler retains the native CommandTerm reset/countdown/compute
lifecycle. command is float32[N,3]: sample vx~U[0,vmax_family] from the newly assigned

success-rate metric. Curriculum owns bounds and policy; evaluation uses fixed command.

Use native resampling_time_range=(T,T), T=max_episode_length_s+step_dt, and validate

## Implemented evaluation/configuration mechanics — T09–T12

These entries document implementation of approved S14/S34/S35/S66, not new physics
or architecture decisions. Existing approved numeric contracts above remain
unchanged; final Verify/user acceptance is pending.

- `SensorSample` (`labs/sensors/sample.py`) contains borrowed float32 metre `values`,
  bool `valid` of the same spatial shape, float32 `[N]` `capture_time`/`age` in seconds
  since row reset, int64 `[N]` `episode_id`, and bool `[N]` `captured`. Buffers can
  change on own-row capture/reset; clone retained transitions. Repeated held reads
  do not advance physics. Bundle spatial shapes/dtypes/devices and metadata types

  clocks/capture/reset identities raise `RuntimeError`.
- `LowRateTargets` has `.target: dict[str,Tensor]` and `.metadata: dict[str,Tensor]`.
  `low_rate_valid` reports aligned captured rows independently of whether any
  individual pixel/ray is valid. `metric_height_scan` returns held metric heights;
  `sensor_metadata` and `low_rate_target` select established named keys for native
  observation terms. No additional sampling clock is introduced.
- `configure_parkour_evaluation(cfg, family='box', level=0, velocity=1.0,
  mirror_sign=1, seed=0)` modifies/returns a native environment config.
  Family:str is one of six approved families; level:int is0..9; velocity is finite
  float0..3 m/s; mirror_sign:int is±1 with-1 only for tilted stairs/side slope;
  seed:int is nonnegative. Invalid selections raise `ValueError`. The helper
  defaults to2 envs, fixed startup row/family, zero-jitter nominal resets,
  nominal dynamics, no noise or adaptive curriculum. Generator keeps ten native
  difficulty strata; same seed/family/row gives matched mirror canonical geometry.
  Apply after native preset resolution. `make_parkour_evaluation_cfg` creates the
  corresponding unresolved config; registered `eval_env_cfg_entry_point` exposes
  its default case. Native `play_mode()` uses the same deterministic defaults.
- `set_evaluation_terrain(env, env_ids, level:int)` is the native startup event
  assigning the fixed row before the first reset. It updates native terrain rows
  and origins, retaining the column/family. Invalid level raises `ValueError`.
- `reset_parkour_state(..., nominal:bool=False)` uses the approved training jitter
